# (ADR 0027). Both tools read this list, scripts/render/Sources/Render/main.swift
# and scripts/render-iphone.sh, so a language joins them with a line here. The
# list and its format are our own.

# formats for dates, numbers and durations a device in the language shows,
# Unicode's likely one for it, as Locale.Language.maximalIdentifier gives it,

# to left, which mirrors the window, or ltr; and its name in English, for the
# tools' messages.

fr FR ltr French
